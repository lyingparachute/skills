# Details

Concrete values and fixes that sit below the command references. A command reference decides what to do; these files say exactly how. The project's DESIGN.md, its tokens, and a pinned brief override every default here.

| File | Load when |
| --- | --- |
| [motion.md](motion.md) | Building, tuning, or reviewing any web animation or transition |
| [motion-performance.md](motion-performance.md) | An animation stutters or drops frames, or will play while the page is busy |
| [surfaces.md](surfaces.md) | Nested radii, optical alignment of icons, shadows versus borders, image outlines, hit areas |
| [typography.md](typography.md) | Text wrapping, font smoothing, tabular numbers |
| [worst-case.md](worst-case.md) | Stress-testing a component with realistic worst-case data behind a toggle |
| [mobile-web.md](mobile-web.md) | A web app is built for, or feels wrong on, a phone |

Motion, motion performance, worst-case data, and mobile web guidance are adapted from [emilkowalski/skills](https://github.com/emilkowalski/skills) (MIT, Copyright (c) 2026 Emil Kowalski).
