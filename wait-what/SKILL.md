Re-pitch the last thing you said, with enough context to stand on its own.

Use Simplified Technical English: one instruction per sentence, short common words, active voice, no clause stacking. Keep the precise technical terms and drop everything ornamental. `no-ai-slop` holds as always.

Use the project's own vocabulary. Read `CONTEXT.md` for it, following `CONTEXT-MAP.md` to the right one where a repo has several. Where neither file exists, take the vocabulary from the code, the ticket, or whatever the user themselves called things in this conversation.

The pitch failed, not the reader. So change the explanation: a different angle, a smaller first step, a concrete example, or the mechanism instead of the summary.
